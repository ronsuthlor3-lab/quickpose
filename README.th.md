# QuickPose — ตัวจับเวลาฝึกวาดท่าทาง

**▶ ใช้งานได้เลยที่: https://ronsuthlor3-lab.github.io/quickpose/**

[English](README.md)

ฝึกวาด gesture drawing แบบคลาสศิลปะ: รูปอ้างอิงขึ้นทีละภาพ จับเวลา แล้วเปลี่ยนภาพอัตโนมัติ
ใช้ **รูปอ้างอิงของคุณเอง** (เลือกทั้งโฟลเดอร์ได้) หรือ **โจทย์เป็นข้อความ** ถ้าไม่มีรูป
รูปเปิดในเครื่องเท่านั้น **ไม่ถูกอัปโหลดไปไหน** ฟรี ไม่ต้องสมัคร

## มีอะไรบ้าง

- **ตั้งเวลาแบบคลาส:** วอร์มอัพ 10×30 วิ · คลาสมาตรฐาน 30 วิ → 1 นาที → 5 นาที → 10 นาที · เร็ว 20×30 วิ · ท่ายาว หรือพิมพ์เอง เช่น `10x30s, 5x1m, 2x5m`
- **สุ่มไม่ซ้ำ:** ใช้รูปครบทุกรูปก่อนวนซ้ำ และไม่ขึ้นรูปเดิมติดกัน
- **สลับซ้าย-ขวาแบบสุ่ม** กันการจำภาพ และ **โหมดขาวดำ** สำหรับฝึกน้ำหนัก
- **เสียงเตือน** 3 วินาทีสุดท้าย และ **ไม่ให้หน้าจอดับ** ระหว่างฝึก
- **ปุ่มลัด:** Space หยุด/เล่น · ← ย้อน · → ข้าม · Esc จบ
- **สถิติ:** วันติดกัน นาทีใน 7 วัน จำนวนภาพทั้งหมด (เก็บในเบราว์เซอร์นี้)
- **โจทย์ข้อความ 32 แบบ** ภาษาไทยและอังกฤษ เขียนขึ้นใหม่สำหรับโปรเจกต์นี้

## หารูปอ้างอิงจากไหน

ใช้รูปที่คุณถ่ายเอง หรือรูปจากแหล่งที่อนุญาตให้ใช้ฝึกวาดได้ โปรแกรมนี้ไม่มีรูปในตัว เพื่อไม่ละเมิดลิขสิทธิ์ใคร
